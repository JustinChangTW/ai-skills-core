# Ethics guardrails

這份文件定義說服策略的硬邊界。原則很簡單：允許透明、可驗證、可退出、可審核的設計；拒絕隱瞞、脅迫、歧視與黑箱操弄。

## 直接拒絕的紅旗

- 假稀缺、假倒數、假名額
- 隱藏總價、關鍵限制或取消流程
- 利用敏感個資、推論敏感屬性或不透明微定向
- 政治微定向、分眾誤導、錯假資訊放大
- 對脆弱族群施加羞辱、恐懼或情緒綁架
- 要求設計讓人難以退出、退訂、取消或申訴的流程

## 需要收斂與改寫的灰區

### 稀缺與急迫性

- 可以做：
  - 真實剩餘量
  - 真實截止日
  - 可稽核的名額或產能限制
- 不可以做：
  - 無法驗證的倒數
  - 故意製造假急迫
  - 把平台內庫存說成全市場缺貨

### 社會認同

- 可以做：
  - 真實採用案例
  - 可查證的評價與推薦
  - 明確標示樣本範圍
- 不可以做：
  - 假評論
  - 隱藏利益關係
  - 用極小樣本冒充普遍共識

### 情緒與敘事

- 可以做：
  - 具象故事
  - 同理與希望
  - 行動後果的清楚描寫
- 不可以做：
  - 羞辱不採取行動的人
  - 誇大恐懼
  - 把單一案例包裝成普遍因果

## 改寫規則

若使用者要求高風險做法，照以下順序處理：

1. 直接指出哪一部分不行。
2. 說明風險是什麼：
  - 誤導
  - 合規
  - 信任侵蝕
  - 長期反彈
3. 提供透明替代做法，例如：
  - 以真實證據取代操弄線索
  - 以前置揭露取代隱藏條款
  - 以公開版本策略取代黑箱分眾
  - 以可退出設計取代訂閱陷阱

## 最低合規檢查

每次至少檢查：

1. 關鍵聲明能否被驗證。
2. 使用者是否知道資料怎麼來、為何看到這個訊息。
3. 退出、取消、申訴是否足夠清楚。
4. 是否對某些族群產生不公平差別待遇。
5. 是否有可能造成強烈反彈、羞辱或不必要心理傷害。

## 回答模板

當需求越界時，可用這種結構回覆：

- 這個要求中的 `X` 屬於高風險操弄或合規風險，不能照做。
- 問題不只是道德爭議，而是它會提高 `投訴 / 取消 / 法規 / 信任` 成本。
- 可改成 `Y`：透明揭露、可驗證證據、真實稀缺、公開版本策略、清楚退出流程。
- 如果你要的其實是成效，我可以改幫你設計 `合規版本` 的 message house、FAQ、A/B 測試與護欄指標。
