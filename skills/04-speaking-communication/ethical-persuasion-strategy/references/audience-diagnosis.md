# Audience diagnosis

這份文件提供說服策略最小可用的受眾診斷欄位，避免一開始就陷入人口統計刻板印象。

## 必看變數

### 1) 涉入度與能力

- 問題：
  - 這件事對他有多重要
  - 他有沒有時間、知識、注意力看完細節
- 解讀：
  - 高涉入 + 高能力：優先論證品質、證據、比較表、試點與反對點回應
  - 低涉入 + 低能力：優先可信來源、簡化訊息、明確 CTA 與摩擦降低

### 2) 既有立場與身份牽涉

- 問題：
  - 對方目前是支持、中立、反對，還是表面支持但行為不動
  - 這件事是否碰到他的專業、權力、角色認同
- 解讀：
  - 身份威脅高時，先處理尊重、自主感與風險承擔，不要直接壓他改變

### 3) 損失敏感度與風險偏好

- 問題：
  - 對方怕失去什麼
  - 他更在意獲益，還是避免踩雷
- 解讀：
  - 損失敏感高：適合明確化不作為成本、風險逆轉、保固或試行
  - 風險承受高：可強調速度、成長與領先優勢

### 4) 信任基線

- 問題：
  - 他信不信你、你的品牌、你的制度或數據來源
  - 現在缺的是能力信任、誠信信任，還是善意信任
- 解讀：
  - 信任低時，先補第三方證據、透明揭露與可驗證承諾

## 快速診斷表

用下表快速整理：

| 變數 | 狀態 | 對策略的影響 |
| --- | --- | --- |
| 涉入度 | 高 / 中 / 低 | 決定偏論證還是偏線索 |
| 理解能力 | 高 / 中 / 低 | 決定資訊密度與呈現方式 |
| 既有立場 | 支持 / 中立 / 反對 | 決定語氣與阻力處理 |
| 身份威脅 | 高 / 中 / 低 | 決定是否先降抗拒 |
| 損失敏感度 | 高 / 中 / 低 | 決定框架與承諾 |
| 信任基線 | 高 / 中 / 低 | 決定要先補可信度還是直接推行動 |

## 常見判讀錯誤

- 把「不採用」誤判成「不理解」，其實對方可能是怕背責任。
- 把「轉換低」誤判成「文案不夠刺激」，其實可能是信任或退出風險。
- 把「員工反對」誤判成「抗拒變革」，其實可能是制度與激勵沒有對齊。
- 把「客戶不回覆」誤判成「沒有興趣」，其實可能是決策成本太高或證據不足。

## 最小輸出要求

每次至少要回答：

1. 誰在決定，誰在影響。
2. 他偏論證還是偏線索。
3. 他最怕失去什麼。
4. 他現在最不信任哪一塊。
5. 若不處理這個阻力，任何話術都會在哪裡失效。
