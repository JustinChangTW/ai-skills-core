# 口說結構選擇

## 快速路由

| 情境 | 主結構 | 最小骨架 |
|---|---|---|
| 表達觀點、即席題 | PREP | 結論—理由—例子—重申 |
| 面試經驗、事件說明 | STAR | 情境—任務—行動—結果／反思 |
| 主管報告、決策 | 結論先行金字塔 | 建議—三個理由—證據—需要決定 |
| 問題或提案 | SCQA | 現況—變化／衝突—問題—答案 |
| 事件異常／延期 | 狀況處置 | 現況—原因—影響—處理—需要協助 |
| 教人理解複雜概念 | 白話教學 | 它是什麼—為何重要—生活比喻—例子—避免誤解 |
| 臨時腦袋空白 | 三格救援 | 我的結論—兩個原因—一個例子 |

## 使用原則

- 先回答，再解釋；面試 STAR 也先用一句話表明能力或結果。
- 15秒只保留結論與一個理由；30秒加入例子；60秒最多三點。
- 結構是記憶扶手，不要把 PREP、STAR、SCQA 全塞進同一回答。
- 提詞卡只寫關鍵詞與數字，不寫完整句。

## 救援句

- 「我先講結論：＿＿。」
- 「這件事有兩個重點。」
- 「我用一個實際例子說明。」
- 「我重新整理一下，最重要的是＿＿。」
- 「這部分我目前不能確定；已知的是＿＿，我會在＿＿前確認。」

救援句用於重新取得結構，不用來拖延或掩飾未知。
