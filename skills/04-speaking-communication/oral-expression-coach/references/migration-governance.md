# Migration governance

## Compatibility

更新時同步檢查名稱、UI metadata、觸發與負面案例、輸出欄位、參考檔路由、健康安全與不虛構邊界。

## Rename

只有名稱造成可測量的觸發混淆時才改名；記錄新舊名稱、受影響 prompts、相容期間與回退方式。

## Split

三分鐘故事演講、說服策略、簡報規劃與醫療語言治療保持獨立；新增需求破壞主要工作時拆分，不擴成萬能溝通 Skill。

## Merge

只有主要工作、工具、輸出與安全邊界一致，且鄰近觸發測試證明混淆下降時才合併。

## Deprecate

被邊界一致且更完整的 Skill 取代，或無法維持錄音／逐字稿證據規則時，標示退役並提供替代路徑。

## Rollback

更新造成虛構經歷、無音訊評聲音、醫療越界、一次塞入過多回饋或鄰近 Skill 誤觸時，回退到最後通過驗證的版本。

## Migration Evidence

記錄舊版／新版、原因、測試、影響檔案、相容風險、回退方式、負責人及下次檢查日期。
