# 口語表達教練

診斷並訓練繁體中文口語表達，涵蓋即席回答、會議發言、主管報告、自我介紹、面試、問答、說明複雜概念、語速停頓、語調音量、贅詞及台風。當使用者提到口語表達、說話沒重點、容易緊張、腦袋空白、講太長、離題、贅詞、即席、PREP、STAR、會議怎麼說、面試回答、錄音或逐字稿講評、聲音表情或表達訓練時使用。輸出診斷、示範說法、限時口說骨架、刻意練習與回饋；不代替語言治療或醫療診斷，不用於純講稿潤色、三分鐘故事演講、簡報頁面規劃或操弄型說服策略。
