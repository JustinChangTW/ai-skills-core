# 關注點溝通助手

依實際對話線索分析對方的關注點、情緒、顧慮、需求與共同利益，設計自然、尊重且可推進關係的說法。Use when 使用者問「怎麼回」「下一句說什麼」「怎麼跟對方談」「如何說服或協調」「對方在意什麼」，或要處理朋友、家庭、伴侶、親子、手足、長輩、交友、同事、主管、部屬、客戶、房仲、議價、衝突、道歉、拒絕、關懷、回饋、演講受眾、TM、TED、講師班、課程、簡報或提案中的人際溝通。也用於改寫訊息、分析對話截圖、準備多種回覆及預測下一輪對話。若只是查詢定義、日期、規則、時間或其他單純事實，不使用。
