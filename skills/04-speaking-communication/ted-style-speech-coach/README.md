# TED 風格演講教練

將主題、經驗或草稿發展成 3、6、12 分鐘 TED 風格觀點演講與排練方案。當使用者說「TED 演講教練」「幫我做 TED 講稿」「把這稿改得像 TED」「設計 12 分鐘演講」時使用。Primary job 是觀點型演講設計與診斷。Do not use for 台北市健言社規則、投影片製作或泛用口語訓練，也不代表 TED 官方認證。成功結果是核心觀點清楚、故事真實、事實可追溯且可上台排練。
