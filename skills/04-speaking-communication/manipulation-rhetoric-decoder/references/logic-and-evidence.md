# 邏輯與證據檢查

## 常見結構

- 假兩難：只給兩個選項，隱藏其他可能。
- 稻草人：把對方主張改弱、改極端再攻擊。
- 偷換概念：同一詞在不同句子換了定義。
- 人身／身份攻擊：用人物評價取代論證。
- 訴諸無知：沒證明錯，所以一定對。
- 循環論證：結論只是換句話重複前提。
- 選擇性證據：只列有利案例，忽略基準、失敗與反例。
- 相關當因果：兩者同時變化就宣稱一方造成另一方。
- 倖存者偏差：只看成功留下者。
- 移動門柱：對方提出證據後不斷改標準。

## 六個證據問題

1. 原始主張能否具體、可否證？
2. 來源是誰，是否有利益衝突？
3. 資料何時、在哪裡、對誰適用？
4. 分母、基準、樣本與比較組是什麼？
5. 有哪些反例、不確定性與替代解釋？
6. 證據支持的是描述、相關、因果，還是只支持可能性？

## 雙重防呆

- 有操弄手法，不代表事實必然錯。
- 有部分事實正確，不代表結論、期限與要求合理。

最終把內容拆成：事實真偽、推論有效性、表達操弄性、行動風險四條獨立結論。
