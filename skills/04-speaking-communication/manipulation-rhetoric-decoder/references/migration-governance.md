# Migration governance

## Compatibility

更新時同步檢查名稱、UI metadata、觸發／負面案例、四條獨立結論、風險分級、查證與不指控邊界。

## Rename

只有名稱造成可測量的觸發混淆時才改名，記錄新舊名稱、受影響 prompts、相容期間與回退方式。

## Split

一般事實查核、政治研究、法律定性及說服策略保持獨立；新增需求破壞主要工作時拆分。

## Merge

只有主要工作、工具、輸出與安全邊界一致，且鄰近測試證明誤觸下降時才合併。

## Deprecate

被邊界一致且更完整的能力取代，或無法維持證據與不指控規則時，標示退役並提供替代路徑。

## Rollback

更新造成無證據定罪、過度觸發、提供操弄優化或忽略高風險安全步驟時，回退到最後通過驗證的版本。

## Migration Evidence

記錄版本、原因、測試、影響檔案、相容風險、回退方式、負責人及下次檢查日期。
