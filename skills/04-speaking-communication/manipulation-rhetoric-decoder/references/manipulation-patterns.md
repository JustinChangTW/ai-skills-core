# 心理與話術模式

## 判斷原則

任何模式都只是一項訊號。必須同時檢查是否隱藏重大資訊、放大壓力、限制選擇、提高退出成本，以及是否涉及重要利害。

| 模式 | 常見訊號 | 破解測試 |
|---|---|---|
| 巴納姆效應 | 模糊、普遍、正反兼容的人格描述 | 換成多數人是否仍成立？什麼證據能證明它錯？ |
| 假稀缺／急迫 | 只剩今天、最後名額、錯過永遠沒有 | 正式期限、庫存及規則在哪？稍後決定的真實成本？ |
| 從眾 | 大家都買、同業都做、聰明人都知道 | 樣本、比例、比較群體與反例？ |
| 權威 | 專家說、名人推薦、國際認證 | 專業範圍、利益關係、完整來源與認證範圍？ |
| 恐懼訴求 | 放大危險，再宣稱唯一解方 | 基準風險、替代方案及未購買的真實後果？ |
| 身份／道德綁架 | 真正孝順／愛家／專業的人都會 | 決策事實與身份評價是否被故意綁在一起？ |
| 互惠壓力 | 都免費幫你了、至少買一點 | 贈與是否附帶事前揭露的義務？ |
| 承諾一致 | 你剛才都同意了、只差最後一步 | 前一步是否等同本次承諾？能否重新評估？ |
| 沉沒成本 | 已投入這麼多不能放棄 | 未來成本效益是否仍合理？過去投入能否收回？ |
| 腳在門內 | 先小要求，再逐步加大 | 完整最終成本與義務是否一開始揭露？ |
| 隔離與秘密 | 不要告訴家人／銀行／同事 | 為何不能找獨立第三方確認？ |
| 煤氣燈式否定 | 你太敏感、都是你記錯 | 有無紀錄、具體事件與可核實第三方？ |
| 資訊超載 | 大量術語、條款、數字讓人放棄比較 | 能否用一頁列總成本、風險與退出條款？ |

## 巴納姆效應專項

提高信心的組合：普遍需求＋正面自我形象＋輕微負面＋正反特質＋模糊時間＋讓讀者自行補例子。破解時要求具體行為、時間、比較基準、預先設定的判準與反例。

透明演講中的共同經驗不必然是巴納姆操弄；若快速轉入真實具體故事、沒有宣稱洞察個人，也沒有用於高壓交易，通常屬一般共鳴。
