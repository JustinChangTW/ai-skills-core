# 操弄話術破解

分析文章、廣告、對話、影片逐字稿、課程、房仲、投資、保險、直銷、職場及詐騙訊息中的操弄話術、巴納姆效應、情緒壓力、認知偏誤與邏輯謬誤。當使用者說「這是不是話術」「有沒有操弄」「破解這段文案」「巴納姆效應」「情緒勒索」「假稀缺」「恐嚇行銷」「洗腦」「偷換概念」「房仲／課程／投資話術」時使用；輸出原句標註、機制、證據、風險與信心、事實查核、去操弄後主張及可直接回覆的破解腳本。不用於替使用者設計操弄、僅做一般事實查核、純邏輯教學或把所有情緒與說服一律判成惡意。
