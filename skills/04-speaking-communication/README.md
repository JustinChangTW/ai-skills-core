# 口語與溝通

訓練口語表達、倫理說服，以及辨識巴納姆效應與操弄話術。

本分類目前收錄 **3 個 Skills**。若任務跨越多個分類，先依主要交付成果選擇 Skill，再視需要交接其他能力。

## Skills 清單

| Skill | 中文名稱 | 主要用途 |
|---|---|---|
| [`ethical-persuasion-strategy`](ethical-persuasion-strategy/README.md) | Ethical Persuasion Strategy | 在使用者要設計說服策略、提案溝通或反對點 FAQ 時使用 |
| [`manipulation-rhetoric-decoder`](manipulation-rhetoric-decoder/README.md) | 操弄話術破解 | 分析文章、廣告、對話、影片逐字稿、課程、房仲、投資、保險、直銷、職場及詐騙訊息中的操弄話術、巴納姆效應、情緒壓力、認知偏誤與邏輯謬誤 |
| [`oral-expression-coach`](oral-expression-coach/README.md) | 口語表達教練 | 診斷並訓練繁體中文口語表達，涵蓋即席回答、會議發言、主管報告、自我介紹、面試、問答、說明複雜概念、語速停頓、語調音量、贅詞及台風 |

## 使用方式

1. 先從上表選擇最接近主要成果的 Skill。
2. 點進 Skill 的 `README.md` 查看用途、適用情境與快速指令。
3. 在支援 Skills 的環境中直接描述任務，或用 `$skill-name` 明確指定。
4. 真正影響 AI 執行行為的是各 Skill 目錄內的 `SKILL.md`。

回到 [Skills 總目錄](../../CATALOG.md) 或 [版本庫首頁](../../README.md)。
