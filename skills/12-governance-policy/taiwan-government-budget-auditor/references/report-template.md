# 政府預算查核報告模板

## 1. 一句話結論

使用「成立／部分成立／誤導／錯誤／證據不足」，並限定查核的主張與時間點。

## 2. 原始主張

| 主張 | 提出者／來源 | 日期 | 類型 | 待查內容 |
|---|---|---|---|---|

## 3. 四基準比較

| 基準 | 金額 | 科目層級 | 文件與定位 | 備註 |
|---|---:|---|---|---|
| 上年度法定預算 |  |  |  |  |
| 上年度決算／實際執行 |  |  |  |  |
| 本年度原編預算 |  |  |  |  |
| 本年度三讀後法定預算 |  |  |  |  |

若尚未三讀，把最後一列改為「目前審議狀態」，不得填入提案數冒充結果。

## 4. 刪除與凍結

| 類型 | 金額 | 明確分母 | 比例 | 最終決議 | 條件／狀態 |
|---|---:|---:|---:|---|---|

明列公式；刪除率與凍結率分開，不提供「合計被砍率」。

## 5. 程序與理由

依日期列出提案、審查、協商、三讀／議決及解凍。初始提案理由與最後決議理由分欄。

## 6. 實際影響

| 影響說法 | 證據鏈 | 等級 | 限制 |
|---|---|---|---|

## 7. 判定理由

回答四題：

1. 相較於什麼？
2. 刪凍了哪裡？
3. 最後為什麼刪凍？
4. 最後真的少了什麼？

## 8. 資料缺口

列出尚未公布、無法對齊或必須等待決算／解凍結果才能判斷的事項。

## 9. 來源

只列實際使用的來源；每個關鍵數字應能回到具體文件位置。
