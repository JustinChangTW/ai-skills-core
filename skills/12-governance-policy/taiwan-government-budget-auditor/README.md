# 臺灣政府預算查核員

查核臺灣中央或地方政府預算爭議，區分提案與三讀結果、刪除與凍結，核對預算與決算基準，並評估可證實的業務影響。當使用者問「預算被砍多少」「凍結是否等於刪除」「某部會會不會停擺」或貼預算新聞要求查證時使用。Do not use for 政黨立場宣傳、一般財報分析或只有政策價值判斷而沒有預算事實爭點。成功結果是每個數字有來源、分母清楚、程序狀態正確，且事實與推論分開。
