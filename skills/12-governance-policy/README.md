# 治理、政策與事實查核

查核政府預算、政策、議會決議與公共爭議中的可驗證事實。

本分類目前收錄 **1 個 Skills**。若任務跨越多個分類，先依主要交付成果選擇 Skill，再視需要交接其他能力。

## Skills 清單

| Skill | 中文名稱 | 主要用途 |
|---|---|---|
| [`taiwan-government-budget-auditor`](taiwan-government-budget-auditor/README.md) | 臺灣政府預算查核員 | 查核臺灣中央或地方政府預算爭議，區分提案與三讀結果、刪除與凍結，核對預算與決算基準，並評估可證實的業務影響 |

## 使用方式

1. 先從上表選擇最接近主要成果的 Skill。
2. 點進 Skill 的 `README.md` 查看用途、適用情境與快速指令。
3. 在支援 Skills 的環境中直接描述任務，或用 `$skill-name` 明確指定。
4. 真正影響 AI 執行行為的是各 Skill 目錄內的 `SKILL.md`。

回到 [Skills 總目錄](../../CATALOG.md) 或 [版本庫首頁](../../README.md)。
