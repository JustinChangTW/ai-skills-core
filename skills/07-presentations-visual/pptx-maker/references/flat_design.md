# Flat Design for Slides

這份 reference 只在使用者明示指定扁平化設計（Flat Design），或品牌規範已確認採用此語言時才讀取。它是可選視覺語言，不是 `pptx-maker` 的預設答案。

## Purpose and fit

- 適合需要簡潔、快速掃讀、低裝飾、圖示化與高可維護性的投影片。
- 適合資訊圖、流程頁、功能頁、概念示意頁與教學型簡報。
- 若需求必須依賴材質感、強烈空間深度、擬物感或複雜情緒氛圍，不要硬套 Flat Design。

## Execution rules

### Visual language
- 使用簡單的 2D 元素、清楚的幾何形與留白，避免不必要的紋理、材質模擬與厚重光影。
- 以清晰、可辨識、可縮放為優先，降低視覺噪音。

### Typography and color
- 優先使用清楚的 sans-serif 字體，維持簡單、直接的字體系統。
- 色彩可鮮明，但要受控；以高對比與清楚分群為主，不要因為求活潑而失控。
- 用大小、位置與色彩建立層級，不要依賴 3D 效果。

### Grid and iconography
- 使用穩定 grid 與一致間距，保持頁面秩序。
- 圖示與插圖應簡化成基本形狀與清楚輪廓，優先高辨識性。
- 避免混入過多不同筆觸、不同投影規則或不同細節密度的圖示。

### Caution
- Flat Design 的問題不是「太平」，而是過度去除層級後會讓互動或主次不清。
- 做簡報時可接受極輕微的階層提示，但不要把它滑成另一種重陰影風格。

## QA checklist

- 是否維持 2D、低裝飾、低噪音，而不是混進厚重陰影與材質模擬。
- 是否靠字級、色彩與位置建立層級，而不是所有元素都一樣扁平同重。
- 圖示、插圖與色塊是否簡潔一致，沒有風格混雜。
- 是否仍保有足夠可讀性與主次，不因過度簡化而變得難判讀。

## Common failure modes

- Symptom: 說是 Flat Design，但實際上只是把陰影拿掉，頁面仍然混亂。
  - Cause: 只做表面去裝飾，沒有建立清楚的 grid、層級與間距。
  - Fix: 回到 build spec，先重整資訊層級、版面對齊與間距，再刪除不必要效果。

- Symptom: 頁面很乾淨，但重要資訊不突出，觀眾不知道先看哪裡。
  - Cause: 把所有元素做得同樣扁平，沒有用字級、色彩與位置拉出主次。
  - Fix: 增加清楚的主標與關鍵數字對比，讓一個主訊息先被看到。
