# Bento Style for Slides

這份 reference 只在使用者明示指定 Bento 風格，或品牌規範已確認採用 card-based / bento grid 語言時才讀取。它是可選視覺語言，不是 `pptx-maker` 的預設答案。

## Purpose and fit

- 適合把多個功能、指標、案例或訊息模組放在同一頁中，同時維持可掃讀性與清楚主次。
- 適合產品介紹、功能總覽、指標 dashboard 式頁面、案例集合頁。
- 若內容本質是單一路徑敘事、需要長段推理，或一頁只該有單一巨大主張，不要硬套 Bento。

## Execution rules

### Layout structure
- 以欄列格線建立卡片式模組，允許不同卡片跨欄跨列，但所有卡片仍需對齊同一套 grid。
- 大卡片承載主訊息，小卡片承載輔助訊息；尺寸差異必須服務層級，而不是只是為了「看起來像 Bento」。

### Card strategy
- 每張卡片都要有明確職責，例如 KPI、功能亮點、流程步驟、案例、截圖、引言或 CTA。
- 卡片內部結構也要一致，避免每格都像不同模板拼湊。
- 單頁卡片數量要受控，通常以 3-7 個模組為宜；若卡片太多、太碎，觀眾只會看到雜訊。

### Visual hierarchy
- 透過卡片尺寸、跨欄跨度、色塊、圖像比例與字級建立主次。
- 最重要的卡片應先被看見，不能每格都長得一樣重。

### Color and boundary
- 可使用較柔和的中性色背景與卡片底，但必須維持足夠對比與一致間距。
- 卡片可以有圓角與淡陰影，但只限於輕量結構提示；一旦陰影、玻璃感、漸層過重，就會從 Bento 變成另一種風格。

### Media and density
- Bento 很適合混合數字、短文案、icon、產品截圖與小圖表，但每張卡片只保留一個主要視覺重點。
- 若卡片同時塞滿圖、文、icon、badge、按鈕，應先刪減。
- 若最終載體是大型投影，必須特別防止卡片碎裂感與字級過小；必要時減少卡片數量、拉大跨欄，或拆成多頁。

## QA checklist

- 卡片大小是否真的反映資訊層級，而不是隨機拼貼。
- 單頁卡片數量是否受控，沒有變成滿版儀表板噪音。
- 卡片間距、圓角、描邊、陰影與內邊距是否一致。
- 每張卡片是否只有一個主視覺重點，而不是所有元素互搶注意力。
- 若最終是線下投影，卡片內字級是否仍足夠大，沒有因為 Bento 分格而犧牲可讀性。

## Common failure modes

- Symptom: 自稱 Bento 風格，但結果只是把內容切成很多卡片，主次不明、像儀表板噪音。
  - Cause: 沒有用卡片尺寸與跨欄關係表達層級，只是把所有模組平均切碎。
  - Fix: 回到 build spec，重排主卡與輔卡，減少卡片數量，讓最大卡片承載最重要訊息，其餘卡片只補充。

- Symptom: Bento 頁面在電腦上好看，但投影時每張卡片都太小、太密，觀眾無法快速掃讀。
  - Cause: 把產品頁或 dashboard 的螢幕式 Bento 直接搬進簡報，沒有依放映距離重新分配模組與字級。
  - Fix: 依投影條件減少卡片數、放大主卡跨度與字級，必要時把一頁 Bento 拆成兩頁以上。
