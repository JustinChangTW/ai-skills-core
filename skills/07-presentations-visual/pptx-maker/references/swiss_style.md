# Swiss Style for Slides

這份 reference 只在使用者明示指定瑞士國際字體風格（Swiss Style / International Typographic Style），或品牌規範已明確要求時才讀取。它是可選視覺語言，不是 `pptx-maker` 的預設答案。

## Purpose and fit

- 用來強化客觀性、秩序感、清晰度與高衝擊對比。
- 適合內容已相對定稿，且需求偏向極簡、理性、非裝飾性版面時使用。
- 若任務需要溫暖敘事、插畫感品牌、高度情緒化視覺，或既有品牌風格明顯不是這一路，不要硬套。

## Execution rules

### Layout structure
- 先建立明確網格，所有文字、圖片、色塊都必須貼齊欄列或基線，不允許憑感覺浮動。
- 預設採非對稱平衡與靠左對齊，不把置中當常態。

### Typography
- 優先使用中性無襯線字體。若環境與授權允許，可用 Helvetica / Univers 類；若不可用，選相近的中性 sans-serif 替代。
- 中文以可讀性高的黑體系為主，不使用新細明體、標楷體或帶強烈書寫感的字體。
- 用粗細與尺寸製造層級。標題可用 Bold 到 Black，內文維持 Regular 到 Medium；避免所有文字都卡在中等粗細。
- 標題與內文需保有明顯倍數差，不靠陰影或裝飾撐存在感。

### Color and geometry
- 畫面大多數區域用黑、白、灰建立高對比。
- 只允許極少量單一強調色，而且只能拿來導引視線、標記章節或凸顯關鍵詞，不拿來做情緒性裝飾。
- 大量留白是結構的一部分，不是待填滿區域。
- 若要分割畫面，使用銳利、貼齊網格的矩形或線性幾何，不加圓角、漸層、陰影、發光或擬物效果。

### Imagery
- 若要用圖，優先選客觀、紀實、對比清楚的照片。
- 圖片不是縮成小卡片放中央，就是滿版或嚴格嵌入網格矩形。
- 避免卡通插圖、漂浮去背圖與無關的情緒底圖。

### Content shaping
- 不要把瑞士風格做成 5 個長 bullet points 的傳統課堂投影片。
- 若有多個重點，優先拆頁，或改成並列模組化區塊。
- 真正需要清單時，也要維持極短標籤與嚴格對齊。

## QA checklist

- 是否真的有網格與基線對齊，而不是只用了黑白配色假裝是 Swiss Style。
- 是否以左對齊與非對稱平衡為主，而不是把所有東西置中。
- 是否混入不必要的陰影、圓角、漸層、發光、3D、細邊框或裝飾性底圖。
- 是否濫用 bullet list；若仍有大量條列，應先懷疑這份 deck 尚未真正轉成瑞士風格。
- 強調色是否只有單一功能性用途，而不是到處點綴。

## Common failure modes

- Symptom: 自稱瑞士風格，但結果只是黑白配色加大字，版面仍鬆散、置中、靠裝飾撐氣氛。
  - Cause: 只模仿表面配色，沒有真正落實網格、非對稱、零裝飾與字體層級。
  - Fix: 回到 build spec，先把版面重新鎖進網格，刪掉陰影與圓角，改用左對齊、粗細對比與留白建立張力。

- Symptom: 瑞士風格頁面看起來很冷，但資訊仍然塞滿，觀眾只看到一堆條列。
  - Cause: 沒有把清單拆頁或模組化，只是把傳統 bullet slide 換成 Helvetica 類字體。
  - Fix: 把多重要點拆成多頁或並列區塊；表面只保留短標籤、關鍵詞與圖像化結構。
