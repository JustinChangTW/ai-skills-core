# Memphis Style for Slides

這份 reference 只在使用者明示指定 Memphis 風格，或品牌規範已確認採用該語言時才讀取。它是可選視覺語言，不是 `pptx-maker` 的預設答案。

## Purpose and fit

- 適合高能量、反常規、活動宣傳、創意提案、青年文化、品牌實驗或需要強烈個性的簡報。
- Memphis 的關鍵是明亮色彩、幾何形、粗體圖樣與刻意打破「好品味秩序」的 playful tension。
- 若場景高度正式、保守、法規導向或需要權威穩定感，不要硬套 Memphis。

## Execution rules

### Shape and pattern
- 使用幾何形狀、粗圖樣、強對比色塊與帶有玩味的組合。
- 可接受不對稱與受控失衡，但必須仍保有可讀性與主訊息優先。
- 圖樣與形狀要有節奏，不是把各種花樣胡亂堆疊。

### Color
- 可以使用大膽、飽和、甚至衝突感較強的色彩組合。
- 但配色仍需服務主次與文字可讀性，不能讓背景吃掉內容。

### Typography
- Typography 可以更有表情，但不能犧牲投影閱讀。
- 當圖樣與色彩已經很強時，字體系統反而要更克制，避免所有元素同時尖叫。

### Composition
- Memphis 可以打破傳統秩序，但不等於放棄結構。
- 主標、關鍵數字與 CTA 仍要有清楚落點。
- 若用裝飾性圖樣，務必讓它服務節奏與氛圍，而不是和內容搶主角。

## QA checklist

- 是否有明確主訊息，還是只剩下風格噪音。
- 幾何圖樣、色塊與裝飾是否有節奏，而不是失控堆滿。
- 強烈背景下文字是否仍足夠清楚，尤其在投影時。
- 是否把反常規做成「亂」，而不是做成受控的 playful tension。

## Common failure modes

- Symptom: 看起來很花，但完全不知道重點在哪。
  - Cause: 只複製鮮豔圖樣與形狀，沒有建立資訊層級。
  - Fix: 先鎖定主標、主數字與 CTA，再讓圖樣退回輔助角色。

- Symptom: Memphis 風格很強，但正式場合顯得不專業或太吵。
  - Cause: 沒先判斷受眾與場合是否適合這種高噪音語言。
  - Fix: 回到 `style_families.md` 重選風格，或把 Memphis 限縮在封面、章節頁與少數高情緒頁面。
