# Mermaid 圖表製作 Skill

在使用者要用 Mermaid 視覺化流程、時間關係或資訊結構時使用。常見觸發像「畫流程圖」「做時序圖」「把架構整理成 Mermaid」。輸出合適圖型與可貼上的 Mermaid；不直接取代投影片或 UI 設計。

## 基本資料

- Skill ID：`mermaid-diagram`
- 分類：`07-presentations-visual`
- 版本：`未標示`
- 主要指令：[SKILL.md](SKILL.md)

## 快速使用

在支援 Skills 的環境中，可以直接描述任務；若要明確指定，可使用：

```text
$mermaid-diagram 請依我的目標與現有資料完成任務，並列出需要我確認的事項。
```

建議一併提供目標、使用情境、已知資料、限制條件，以及希望取得的成果格式。若資料不足，Skill 會依核心指令只詢問真正影響結果的問題。
