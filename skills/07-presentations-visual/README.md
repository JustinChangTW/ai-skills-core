# 簡報與視覺

規劃簡報、製作 PPTX、自然化版面，以及產生圖像與視覺素材。

本分類目前收錄 **7 個 Skills**。若任務跨越多個分類，先依主要交付成果選擇 Skill，再視需要交接其他能力。

## Skills 清單

| Skill | 中文名稱 | 主要用途 |
|---|---|---|
| [`blender-control`](blender-control/README.md) | Blender 操控工作流 |  |
| [`humanize-presentation-visuals`](humanize-presentation-visuals/README.md) | 簡報自然化設計師 | 在使用者要把 AI 味重、模板化、油亮科技風或每頁都像「標題加三點」的既有簡報重新設計時使用；可診斷敘事與版面、自然化文案、規劃並實際生成封面圖、情境圖、示意圖、資訊圖與背景素材，再串接 PPTX／PDF 製作 |
| [`mermaid-diagram`](mermaid-diagram/README.md) | Mermaid 圖表製作 Skill | 在使用者要用 Mermaid 視覺化流程、時間關係或資訊結構時使用 |
| [`pptx-maker`](pptx-maker/README.md) | Pptx Maker | 在使用者已經有逐頁內容、講稿、模板或 SVG，要真正做成可交付投影片時使用 |
| [`slide-content-planner`](slide-content-planner/README.md) | Slide Content Planner | 將文章、文件、筆記、試算表或零散想法轉成受眾導向、敘事清楚且可直接製作的簡報藍圖 |
| [`visual-line-sticker-production`](visual-line-sticker-production/README.md) | LINE Sticker Production | Create, iterate, validate, and package upload-ready static LINE sticker sets with customizable character style and on-sticker text. |
| [`visual-presentation-production`](visual-presentation-production/README.md) | Visual Presentation Production | Create image-based 16:9 presentations through mandatory brief, exact page-count, outline-layout, style-lock, sample, per-slide generation, QA, and PDF-only delivery gates. Use for talks, workshops, lesson decks, reports, explainers, or branded presentations where each slide is a complete host-generated image. |

## 使用方式

1. 先從上表選擇最接近主要成果的 Skill。
2. 點進 Skill 的 `README.md` 查看用途、適用情境與快速指令。
3. 在支援 Skills 的環境中直接描述任務，或用 `$skill-name` 明確指定。
4. 真正影響 AI 執行行為的是各 Skill 目錄內的 `SKILL.md`。

回到 [Skills 總目錄](../../CATALOG.md) 或 [版本庫首頁](../../README.md)。
