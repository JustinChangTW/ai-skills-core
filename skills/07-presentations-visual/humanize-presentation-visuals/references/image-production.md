# 簡報製圖規則

## 素材分類

- `hero image`：封面或章節頁主視覺，要有明確焦點與留字區。
- `scene`：呈現情境、衝突或人物關係；不得冒充真實客戶案例。
- `diagram`：流程、架構與關係。精確文字和箭頭以原生形狀製作，不讓生成模型直接寫字。
- `infographic`：數值、比較與分類。生成式圖片只負責插畫元素，數據與標籤以確定性工具排版。
- `object`：單一物件或象徵元素；背景與視角要利於裁切。
- `texture/background`：只建立氣氛，不可壓過文字。

## Production brief

每張圖記錄用途、頁碼、媒材、主體、構圖、鏡位、光線、色彩、留白位置、禁止元素、比例及需保留的參考特徵。不要把版面文字要求模型直接畫進圖裡。

先做代表性頁面的 style sample，確認後再延伸。同一份簡報保持媒材、輪廓、光線、鏡頭語言與色彩處理一致；構圖依頁面任務變化。

## QA

- 主體、姿勢、手指、臉部與物件結構合理。
- 沒有亂碼、假 logo、假 UI、錯誤數字或不可驗證文字。
- 留字區乾淨，裁切到 16:9 或目標版位後仍完整。
- 色彩與文字有足夠對比，縮圖下仍看得出焦點。
- 圖像服務頁面任務；若只裝飾，優先不用。
- 與其他頁維持同一視覺世界，但不機械複製同構圖。
