# Slide Content Planner

將文章、文件、筆記、試算表或零散想法轉成受眾導向、敘事清楚且可直接製作的簡報藍圖。當使用者說「做簡報大綱」「規劃投影片」「把文件轉成簡報」「福哥流簡報」「主管版／客戶版」「逐頁規劃」「補講稿」「檢查簡報邏輯」時使用；輸出 GAP 對焦、核心訊息、逐頁內容、視覺布局、講者稿與預想問答。不直接產生或修改 PPTX、Google Slides、SVG 或全頁圖片，成品製作交接給相應投影片製作能力。

## 快速使用

在支援 Skills 的環境中，可以直接描述任務；若要明確指定，可使用：

```text
$slide-content-planner 請依我的目標與現有資料完成任務，並列出需要我確認的事項。
```

建議一併提供目標、使用情境、已知資料、限制條件，以及希望取得的成果格式。若資料不足，Skill 會依核心指令只詢問真正影響結果的問題。
