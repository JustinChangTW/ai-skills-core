# LINE Static Sticker Requirements

Use this reference for ordinary static stickers. Verify current requirements against the official source before a real upload because LINE may revise them.

## Required upload assets

| Asset | Count | Requirement |
| --- | ---: | --- |
| Main image | 1 | 240 × 240 px PNG |
| Sticker images | 8, 16, 24, 32, or 40 | Up to 370 × 320 px PNG; even width and height |
| Chat thumbnail icon | 1 | 96 × 74 px PNG |

- Use RGB/RGBA PNG at 72 dpi or higher.
- Keep every image at or below 1 MB; keep a single upload ZIP at or below 60 MB.
- Use transparent backgrounds and leave roughly 10 px between visible content and the trimmed edge.
- The main image and thumbnail must represent the same character/set as the stickers.

## Product text limits

| Field | Maximum |
| --- | ---: |
| Creator | 50 characters |
| Sticker title | 40 characters |
| Sticker description | 160 characters |
| Copyright | 50 characters |

Asian-language characters and some symbols count as two characters. Use the verifier's conservative counting result as a warning; recheck in Creators Market before submission.

## Review guardrails

- Make each sticker useful in everyday conversation, visually clear, and meaningfully varied.
- Do not submit text-only stickers, a logo-only set, duplicated stickers, spelling errors, or a main/thumbnail image unrelated to the set.
- Exclude advertisements, sale announcements, URLs, personal-data requests, messaging-service references, political solicitation, sexual or violent material, hate or harassment, and harmful or illegal activity.
- Use only original artwork or material for which the creator has provable permission, including portraits, trademarks, and reference images.
