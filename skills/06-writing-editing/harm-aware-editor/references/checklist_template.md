# Manual review checklist

這份 checklist 只用於人工審稿備忘，不是 release gate，也不能覆蓋機械檢查結果。

## Scope

- [ ] 是否有具體原文或明確使用場景。
- [ ] 是否區分審查、改寫、詞彙表、規範建立或研究後改寫。
- [ ] 是否避免把一般潤稿擴大成包容性審查。

## Language Risk

- [ ] 是否標出標籤化、污名、責備、刻板印象或排除語言。
- [ ] 是否檢查創傷再傷害風險，包括逼問、否定經驗、承諾做不到的安全、責怪受害者。
- [ ] 是否檢查身分類別是否與主題相關。
- [ ] 是否檢查語氣是否居高臨下、英雄化、可憐化或物化。

## Rewrite Quality

- [ ] 改寫是否保留原意。
- [ ] 改寫是否更具體、更清楚，而不是更模糊。
- [ ] 改寫是否避免加入原文沒有的承諾或事實。
- [ ] 是否標示當事人偏好、社群偏好或在地文化需確認之處。

## Compatibility

- [ ] 技術、法規、醫療或 API 術語是否保留必要對應。
- [ ] 舊稱是否只在必要時以括號或 code font 標示。
- [ ] 是否避免破壞既有文件、程式碼或引用。
