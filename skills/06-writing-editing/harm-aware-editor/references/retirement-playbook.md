# Retirement Playbook

Retire this skill only if another maintained skill fully covers inclusive-language and trauma-informed review with equivalent trigger coverage, output contract, and eval evidence.

## Retirement Criteria

- No active owner or reviewer for more than one review cycle.
- Updated terminology cannot be maintained safely.
- Another skill supersedes it and includes migration guidance.

## Required Steps

- Mark `status: deprecated` in `skill_lifecycle.yaml`.
- Set `deprecated_by`.
- Preserve a migration note mapping old trigger phrases to the replacement skill.
- Do not delete evals until the replacement skill demonstrates equivalent or better trigger and functional coverage.
