# 論點連貫與階層一致性

人類寫作有觀點，所以起承轉合會服務同一條主張鏈。AI 文字常像文字接龍：每一句局部都順，整體卻會出現論點矛盾、同一概念換詞重複、段落顆粒度忽大忽小、階層關係不清楚等問題。

這份文件用來在 `humanize-text` 中補上 coherence pass。它不是要求所有文字都變成嚴格論文，而是確保讀者能沿著作者的觀點往前走。

## Coherence pass

改寫前先畫出最小主張鏈：

1. 核心主張：這段到底想推進哪個判斷。
2. 支撐理由：作者為什麼這樣判斷。
3. 具體材料：原文有哪些事實、例子、限制或觀察支撐理由。
4. 轉折與限制：作者承認什麼例外、風險或相反情況。
5. 下一步：讀者應理解、回應、決策或行動什麼。

找不到主張鏈時，不要硬編。若原文只是純資訊摘要，就只整理資訊層級；若原文暗含觀點，就把觀點補明，但不能新增事實。

rewrite / edit 任務的 coherence pass 不能只在內部完成。輸出到使用者的 `前置處理` 區塊中，必須有一段可見的「論點連貫檢測」，至少覆蓋論點矛盾、換詞重複、顆粒度跳躍、階層斷裂與假轉折。沒有發現問題時也要明寫檢測結果，例如「未發現明顯論點矛盾，但段落顆粒度偏平均」，避免使用者看不出這一步是否真的做過。

## 改寫幅度判斷

coherence pass 不只用來修句子，也要決定是否需要重排文章。若核心主張太晚出現、原開頭只是在下定義、讀者痛點沒有被看見，或段落順序讓受眾難以做判斷，就不應停在 `light polish` 或普通 `natural rewrite`。此時應升級為 `structural rewrite`，允許重寫開頭一到兩段、合併重複段落、提前主張或調整論點順序。

`structural rewrite` 的邊界是「重排既有材料」，不是自由創作。可以改變資訊出場順序，可以把原文隱含主張提早說清楚，也可以刪掉只換詞重複的段落；但不能新增未提供的數字、案例、來源、第一手經驗或作者沒有支持的價值判斷。

## 常見 AI 斷裂

### 論點矛盾

特徵：

1. 前段說問題是流程，後段又把工具當唯一解。
2. 前段主張保持中立，後段突然強烈推銷。
3. 前段說不新增負擔，後段又要求大量人工維護。
4. 結尾的建議沒有回扣前面的理由。

修法：

1. 選定原文最能支持的主張。
2. 把相反句改成限制、例外或待確認問題。
3. 刪掉無法被原文支撐的跳躍結論。

### 換詞重複敘事

特徵：

1. 同一概念輪流叫「效率」「生產力」「速度」「流程順暢」，但沒有新增資訊。
2. 同一讀者輪流叫「使用者」「客戶」「團隊」「成員」，造成指涉不穩。
3. 每段都在說同一件好處，只是換不同漂亮詞。

修法：

1. 為核心概念選一個穩定名稱。
2. 保留第一次清楚說明，刪掉只換詞的重複句。
3. 後文若再提同概念，必須新增角度，例如原因、例子、限制或下一步。

### 顆粒度跳躍

特徵：

1. 一句談產業趨勢，下一句跳到按鈕設計，再下一句跳回組織文化。
2. 同一段同時塞願景、策略、功能、操作細節與情緒口號。
3. 把大概念和小例子放在同一層，讀者不知道哪個是主、哪個是輔。

修法：

1. 先排階層：主張 > 理由 > 例子 > 限制 > 下一步。
2. 一段只承載一個主控概念。
3. 小細節只在支撐主張時保留；否則移到後段或刪除。

### 假轉折

特徵：

1. 「然而」後面沒有真正反向內容。
2. 「此外」後面只是重複上一句。
3. 「值得注意的是」後面接空泛重要性膨脹。

修法：

1. 真轉折保留，並明確說出差異。
2. 假轉折刪掉，改成自然承接或合併句子。
3. 沒有新資訊的 signpost 不要保留。

### 結尾失焦

特徵：

1. 結尾突然變成「未來可期」。
2. 結尾重複前文，沒有回扣主張。
3. 結尾提出新主題，讓文章像還沒結束。

修法：

1. 回到核心主張或讀者下一步。
2. 若目標是交換看法，留下具體討論點。
3. 若目標是決策，留下取捨或待確認事項。

## 起承轉合的實務版本

不要機械套「起承轉合」四段，而是讓每段有功能：

起：讓讀者知道問題、主張或切入點。

承：補上必要背景、原因或定義，讓讀者跟得上。

轉：處理限制、反例、取捨或真正需要改變方向的地方。

合：回扣主張，落到讀者要理解、回應、判斷或行動的點。

文章很短時，可以把四個功能壓成兩段；文章很長時，每個功能可以拆成多段。重點是功能一致，不是段數一致。

## 自檢

改寫後逐項檢查：

1. 讀者能否用一句話說出這段的核心主張。
2. 每段是否各有一個主控概念。
3. 關鍵概念命名是否穩定。
4. 有沒有只是換詞重複、沒有新增資訊的句子。
5. 轉折詞後面是否真的有轉折。
6. 每個例子、限制與下一步是否回扣主張。
7. 結尾是否收束到原本的預期效果，而不是開新題或喊口號。
