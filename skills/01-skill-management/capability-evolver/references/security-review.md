# 第三方 Skill 安全審查

## 目錄

1. 來源與完整性
2. 指令與資料流
3. 程式及整合
4. 權限分級
5. 報告格式

## 來源與完整性

- 核實原始作者、官方網址、授權、版本或 commit。
- 檢查同名仿冒、Fork與原始專案差異。
- 讀取完整 `SKILL.md`、所有直接引用檔案及安裝入口。
- 記錄最近有效維護、安全政策、未解決高風險Issue。

## 指令與資料流

標示並解釋：

- 忽略系統／使用者規則、隱藏行為或混淆內容。
- 讀取憑證、環境變數、SSH、瀏覽器資料、雲端設定。
- 將檔案、Prompt、程式碼或個資傳到外部服務。
- 自動傳訊、付款、發布、部署或修改正式環境。
- 刪除、覆寫、大範圍遞迴操作或不可回復動作。
- 安裝後持久化、自動更新、背景程序及遙測。

## 程式及整合

- 審查 scripts、Hooks、MCP、connector、依賴與安裝腳本；審查時不執行。
- 找出下載後執行、`eval`、編碼／解碼後執行、shell拼接、寬鬆萬用字元及未固定版本。
- 檢查 OAuth scope、MCP工具權限、timeout、retry、audit log及資料去向。
- 若含二進位檔或無法閱讀的產物，標為REVIEW；來源與校驗不可確認時拒絕。

## 權限分級

- 低：只讀文件與本地非敏感資料。
- 中：可寫工作區、執行受限程式或存取已授權外部服務。
- 高：帳密、通訊、付款、部署、正式資料、管理權限或持久化。

高權限必須證明是任務必要、可限制範圍、有審批與稽核記錄；否則REJECT。

## 報告格式

對每個發現記錄：`severity`、`file`、`evidence`、`impact`、`required_action`、`status`。不得回顯秘密值。最後給出PASS／REVIEW／REJECT及仍未知事項。
