# 軟體與問題解決

拆解問題、整理需求、設計軟體介面並診斷技術整合。

本分類目前收錄 **6 個 Skills**。若任務跨越多個分類，先依主要交付成果選擇 Skill，再視需要交接其他能力。

## Skills 清單

| Skill | 中文名稱 | 主要用途 |
|---|---|---|
| [`alternative-solution-designer`](alternative-solution-designer/README.md) | 替代解法設計師 | 在使用者要比較替代解法、找更簡單或更穩定方案時使用 |
| [`frontend-design`](frontend-design/README.md) | Frontend Design Skill | 在使用者要設計網站、Web App 或元件介面時使用 |
| [`mcp-http-diagnostics`](mcp-http-diagnostics/README.md) | Mcp Http Diagnostics | 在使用者要診斷 MCP HTTP 或 Streamable HTTP 端點、確認連線或列出工具時使用 |
| [`problem-decomposer`](problem-decomposer/README.md) | Problem Decomposer | 在使用者要拆解大型、混亂或高不確定性的難題時使用 |
| [`spec-organizer`](spec-organizer/README.md) | Spec Organizer | 在使用者要把模糊想法整理成可開發 spec 時使用 |
| [`vibe-coding-guidelines`](vibe-coding-guidelines/README.md) | Vibe Coding Guidelines | 在非程式開發者要用 vibe coding 與 coding agent 協作時使用 |

## 使用方式

1. 先從上表選擇最接近主要成果的 Skill。
2. 點進 Skill 的 `README.md` 查看用途、適用情境與快速指令。
3. 在支援 Skills 的環境中直接描述任務，或用 `$skill-name` 明確指定。
4. 真正影響 AI 執行行為的是各 Skill 目錄內的 `SKILL.md`。

回到 [Skills 總目錄](../../CATALOG.md) 或 [版本庫首頁](../../README.md)。
