# Migration governance

## Rename

記錄舊名稱、新名稱、原因及觸發語句相容策略，更新目錄、README、資料夾與所有引用。

## Deprecate

指定替代 Skill、通知文字、生效與移除日期、回復條件；不得讓舊 Skill 繼續搶一般英文或技術教學任務。

## Merge

只有合併後仍維持「證照英文閱讀與詞彙得分」單一責任時允許；不得與完整資安教學或一般英文教學混成萬用老師。

## Split

若拆成題目閱讀與單字記憶，必須分別定義觸發、交接、共同進度與易混字案例。

## Compatibility

檢查 Skill ID、中文名稱、使用者慣用的「保姆級英文小老師」、host設定、目錄與歷史小考資料。

## Migration Evidence

記錄 migration_type、from、to、effective_date、compatibility_policy、references_checked、evals_updated、wrappers_updated 與 release_gate_result。
