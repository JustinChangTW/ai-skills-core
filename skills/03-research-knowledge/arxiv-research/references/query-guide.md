## 欄位與布林查詢

arXiv API 常用欄位：`all` 全欄位、`ti` 標題、`au` 作者、`abs` 摘要、`cat` 分類、`co` 備註。可用 `AND`、`OR`、`ANDNOT` 組合。腳本的普通 query 使用 `all:`；需要複合欄位時直接使用 arXiv API或網路搜尋工具。

## 常用分類

- `cs.CR`：密碼學與安全
- `cs.AI`：人工智慧
- `cs.LG`：機器學習
- `cs.CL`：計算語言學
- `cs.CV`：電腦視覺
- `cs.SE`：軟體工程
- `cs.NI`：網路與網際網路架構
- `cs.DC`：分散式、平行與叢集運算
- `stat.ML`：機器學習統計方法
- `econ.EM`：計量經濟學

完整分類以 arXiv 的 `category_taxonomy` 官方頁為準。

## 搜尋策略

1. 用主題英文術語廣搜，以 relevance 排序。
2. 加入同義詞、技術名稱、資料集、攻擊或防禦名稱。
3. 以分類和 submitted date 找最新研究。
4. 從一篇核心論文追作者、參考文獻及後續引用。
5. 對核心結論查全文，核對論文版本及正式出版狀態。
6. 記錄查詢式、日期、結果數和排除理由，使研究可重現。
