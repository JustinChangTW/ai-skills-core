# 方法蒸餾評分規則

每個候選以 0–2 分評估：來源強度、獨立觸發、步驟可執行性、適用邊界、可觀察結果、失敗／停止條件、與現有 Skill 的區隔。總分 11 分以上且來源強度不得為 0，才可列為 Skill 候選。

## 必備欄位

- 名稱與要解決的任務
- 何時觸發、何時不觸發
- 所需輸入與具體步驟
- 產出與驗收方式
- 假設、邊界、停止條件與常見失敗
- 證據 ID 與確定程度
- 正常、邊界、反例和相鄰 Skill 測試

## 淘汰條件

- 只是常識、口號、人格特質或故事寓意。
- 只能複述作者專有表達，無法轉成一般化操作。
- 無獨立觸發、無法觀察結果或無法設計反例。
- 嚴重依賴過時事實，且無法以現行資料更新。
- 與既有 Skill 的主要責任相同，合併比新增更合理。

候選通過不等於自動安裝；先呈現給使用者選擇，再交 Skill 建置流程。
