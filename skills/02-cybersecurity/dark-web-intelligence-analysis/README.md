# 暗網情資分析

使用合法、免費且可追溯的公開情資，調查帳密外洩、Infostealer、勒索聲稱、駭客活動、惡意網域／IP／URL／檔案雜湊、C2、已遭利用漏洞、仿冒網站、供應鏈與企業曝險。當使用者提到暗網情資、資料外洩、駭客論壇聲稱、勒索軟體、HIBP、Hudson Rock、OTX、Shadowserver、abuse.ch、IOC 查證或「公司是否遭駭」時使用；不直接進入暗網、不購買或下載外洩資料、不測試外洩帳密，也不把單一聲稱當成已證實事件。
