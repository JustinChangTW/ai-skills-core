# 資訊安全

處理資安稽核、安全程式碼、惡意程式與威脅情資分析。

本分類目前收錄 **5 個 Skills**。若任務跨越多個分類，先依主要交付成果選擇 Skill，再視需要交接其他能力。

## Skills 清單

| Skill | 中文名稱 | 主要用途 |
|---|---|---|
| [`dark-web-intelligence-analysis`](dark-web-intelligence-analysis/README.md) | 暗網情資分析 | 使用合法、免費且可追溯的公開情資，調查帳密外洩、Infostealer、勒索聲稱、駭客活動、惡意網域／IP／URL／檔案雜湊、C2、已遭利用漏洞、仿冒網站、供應鏈與企業曝險 |
| [`malware-research-analysis`](malware-research-analysis/README.md) | 惡意程式研究分析 | 安全分析惡意程式家族、別名、檔案雜湊與其他 IOC、行為、感染鏈、MITRE ATT&CK 技術、威脅行為者關聯、偵測獵捕及應變建議 |
| [`secure-code-review`](secure-code-review/README.md) | 安全程式碼審查 | 對 PR、commit、diff、原始碼、設定檔、IaC、API、套件鎖定檔及 SAST／SCA／SARIF 結果執行證據導向的應用安全審查，追蹤輸入到危險操作的資料流、驗證可利用性、降低誤報並提出需人工核准的修補方案 |
| [`taiwan-financial-intelligence-radar`](taiwan-financial-intelligence-radar/README.md) | 臺灣金融情報雷達 | 整合即時資安威脅、網路中斷、全球新聞、股市行情與戰略貿易流向，分析對臺灣金融機構、金融資安、經濟、半導體與科技供應鏈的影響 |
| [`taiwan-isms-audit-expert`](taiwan-isms-audit-expert/README.md) | 臺灣資安稽核專家 | 依 ISO/IEC 27001 與臺灣現行法規、各金融業別規範、主管機關年度檢查重點及同業主要檢查缺失，規劃、執行及報告資安與 ISMS 稽核 |

## 使用方式

1. 先從上表選擇最接近主要成果的 Skill。
2. 點進 Skill 的 `README.md` 查看用途、適用情境與快速指令。
3. 在支援 Skills 的環境中直接描述任務，或用 `$skill-name` 明確指定。
4. 真正影響 AI 執行行為的是各 Skill 目錄內的 `SKILL.md`。

回到 [Skills 總目錄](../../CATALOG.md) 或 [版本庫首頁](../../README.md)。
