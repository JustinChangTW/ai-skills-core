# 官方來源與搜尋規則

## 目錄

1. 來源優先序
2. 核心官方入口
3. 每次查核步驟
4. 引用紀錄格式

## 來源優先序

依序使用：現行法規全文、主管機關法規系統、正式函令／公告、年度檢查重點、主要檢查缺失、裁罰案件、經備查自律規範。新聞或顧問文章只能協助找線索，不可作為唯一法規依據。

## 核心官方入口

- 全國法規資料庫：https://law.moj.gov.tw/
- 金融監督管理委員會：https://www.fsc.gov.tw/
- 金管會主管法規共用系統：https://law.fsc.gov.tw/
- 銀行局：https://www.banking.gov.tw/ 與 https://law.banking.gov.tw/
- 保險局：https://www.ib.gov.tw/
- 證券期貨局：https://www.sfb.gov.tw/
- 金融檢查相關公告：優先從金管會網站搜尋「年度金融檢查重點」「主要檢查缺失」「裁罰案件」。
- 數位發展部：https://moda.gov.tw/
- 國家資通安全研究院：https://www.nics.nat.gov.tw/
- 個人資料保護相關主管機關：依當時有效組織與法規重新核實，不預設機關永遠不變。

## 每次查核步驟

1. 用法規正式名稱搜尋現行全文與沿革。
2. 確認修正日期、施行日期、適用對象及主管機關。
3. 搜尋最近一年修正草案、解釋函令及裁罰。
4. 搜尋當年度檢查重點。
5. 搜尋最近兩期及五年度同業主要檢查缺失。
6. 以業別、資安主題、雲端、委外、備份、存取控制、事件通報等詞交叉搜尋。
7. 保存官方直連，不引用搜尋結果摘要取代原文。

## 引用紀錄格式

| 欄位 | 內容 |
|---|---|
| 要求名稱 | 法規、函令、公告或檢查項目名稱 |
| 效力類型 | 法定要求／監理期待／自律規範／參考 |
| 條次或段落 | 可精確回查的位置 |
| 發布／修正日 | 官方標示日期 |
| 施行狀態 | 已生效／過渡期／草案／停止適用 |
| 適用業別 | 金控、銀行、保險等 |
| 官方網址 | 原始頁面直連 |
| 查詢日 | 實際核實日期 |
| 判讀 | 與本次查核的關聯及限制 |
