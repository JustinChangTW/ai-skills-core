# 巴納姆演講

Create, revise, or coach Traditional Chinese three-minute TM and short public speeches using a Barnum-style shared-experience opening and audience-returning ending around a concrete personal story. Use when the user asks for 健言社、TM、三分鐘演講、即席演講、巴納姆式開頭或結尾、演講首尾呼應、把題目變成故事主軸，或多輪修整短講稿。
