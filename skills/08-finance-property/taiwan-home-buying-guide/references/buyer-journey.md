# 買方入門與決策流程

## 個人需求四層

1. 必要：房數、電梯、室內／權狀坪數口徑、總價、交通、家庭機能。
2. 加分：包裹、垃圾、管理、採光、車位、學區、公園。
3. 可妥協：裝潢、樓層、屋齡、步行距離、行政區。
4. 淘汰：超過安全總價、重大產權／結構疑慮、無法承作貸款、家庭核心需求不符。

先問「如果價格便宜 100 萬，這項缺點會接受嗎？」區分真正紅線與偏好。

## 新手八階段

1. 財務健檢：收入、負債、信用、自備款、預備金、退休前後現金流。
2. 貸款預審：至少比較不同屬性的銀行，取得非約束性初步範圍。
3. 條件建檔：必要／加分／妥協／淘汰與地區替代方案。
4. 市場校準：先看實價與 10–20 間刊登，建立區域單價感。
5. 現場看屋：統一清單、照片與評分；白天、晚上或雨天複看。
6. 文件查核：謄本、說明書、屋況、用途、社區財務與修繕。
7. 出價簽約：先定上限、條件與貸款不足處理，再談斡旋／要約。
8. 驗屋交屋：複驗、設備點交、費用結算、權利移轉與文件保存。

## 安全負擔原則

- 不以銀行願貸最高額等同家庭安全預算。
- 自備款之外，另計交易成本、必要修繕與家庭緊急預備金。
- 同時呈現基準、利率上升、收入下降與鑑價不足情境。
- 年齡接近退休時，另列退休後剩餘本金、月付與收入來源。
- 若使用者未給月收入或負債，只能做物件現金需求，不宣稱負擔安全。

## 多屋比較欄位

需求符合、總持有成本、實價折溢價、銀行適貸性、建物／社區、交通實走、生活機能、災害、轉售性、資料完整度。硬性紅線先淘汰，再對剩餘物件加權；不要讓總分掩蓋單一重大風險。
