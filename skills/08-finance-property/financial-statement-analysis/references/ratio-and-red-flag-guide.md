# Ratio and red-flag guide

## Analysis order

先口徑，再三表，再比率，最後紅旗。

不要反過來做，因為：
- 同一個比率在不同會計準則下可能代表不同意思。
- 沒有先做三表橋接，常會把「看起來好」誤判成「真的好」。

## Core ratio set

### Profitability
- 毛利率 = `(營收 - 銷貨成本) / 營收`
- 營業利益率 = `營業利益 / 營收`
- 淨利率 = `淨利 / 營收`
- ROA = `淨利 / 平均總資產`
- ROE = `淨利 / 平均股東權益`
- ROIC = `NOPAT / 平均投入資本`

### Liquidity and leverage
- 流動比率 = `流動資產 / 流動負債`
- 速動比率 = `(現金 + 短投 + 應收款) / 流動負債`
- 負債權益比 = `總負債 / 股東權益`
- 利息保障倍數 = `EBIT / 利息費用`
- 淨負債 / EBITDA = `(有息負債 - 現金) / EBITDA`
- CFO / 總負債 = `CFO / 總負債`

### Efficiency
- DSO = `365 / 應收帳款週轉率`
- DIO = `365 / 存貨週轉率`
- DPO = `365 x 平均應付帳款 / 銷貨成本`
- CCC = `DSO + DIO - DPO`
- 總資產週轉率 = `營收 / 平均總資產`

### Cash conversion
- CFO / 淨利：看盈餘是否轉成現金
- FCF = `CFO - Capex`
- FCF yield：只有在使用者真的要估值或資本配置判斷時才使用

## Industry watchpoints

### Manufacturing
- 重點看毛利率、存貨、Capex、ROIC、FCF。
- 不要只看 EBITDA，維持性 Capex 很重要。

### Software / tech
- 重點看營業利益率、FCF、遞延收入、研發強度。
- 注意 IFRS 開發成本資本化會扭曲 EBITDA / EBIT 可比性。

### Retail
- 重點看 CCC、同店表現、存貨週轉與租賃負債。
- 注意租賃上表會讓 EBITDA 變好看、負債變更高。

### Financials
- 傳統流動比率、CCC、淨負債 / EBITDA 常不適用。
- 需改看資產品質、淨利差、資本適足等金融專屬指標。

## Red-flag checklist

### Earnings vs cash flow divergence
- 淨利連續成長，但 CFO 長期疲弱或下滑。
- CFO 變好主要來自應付增加，而不是營運改善。

### Working capital stress
- DSO 明顯上升，可能是授信放寬、提早認列或回款變慢。
- DIO 明顯上升，可能是需求轉弱、庫存壓力或跌價風險。

### Margin anomalies
- 毛利率突然跳升，但沒有產品組合、價格、成本或迴轉說明。
- 營業利益改善主要來自一次性處分或分類重整。

### Capitalization and balance sheet buildup
- Capex、無形資產、其他資產突然上升，同時費用率明顯下降。
- 需要檢查是否存在費用資本化、開發成本資本化或重分類。

### Leverage and financing pressure
- 利息保障倍數快速惡化。
- CFO 不足以支撐 Capex、債務到期與股利。
- 借新還舊成為維持現金的主要方式。

### Notes and governance signals
- 大額關聯人交易。
- 重大重編、會計政策變動、估計變動或審計意見異常。
- 「其他資產 / 其他負債」金額顯著，但附註拆解不足。

## Red flags are not verdicts

紅旗的作用是排序風險，不是直接指控舞弊。

每個紅旗都應補四件事：
- 事實是什麼
- 合理解釋可能是什麼
- 為何仍要警戒
- 下一步該追哪個附註、表格或官方來源
