# Output template

Use this output contract exactly unless the user explicitly overrides it.

## Required heading order

```md
## 財報解讀

### 分析範圍與口徑
[公司 / 期間 / 幣別 / 合併或個別 / 會計準則 / 資料來源 / 重要假設]

### 核心發現
[3-5 個高訊號結論，清楚區分已確認事實與推論]

### 三表橋接與盈餘品質
[淨利 -> CFO、非現金項目、營運資金、Capex、借款 / 股利 / 權益變動的一致性]

### 比率、同業與期間對比
[只列與任務相關的比率；若不可比要明示原因]

### 風險紅旗與待確認事項
[紅旗、替代解釋、還缺哪些附註或資料]
```

## Section guidance

### `### 分析範圍與口徑`
- 一開始就講清楚公司、期間、幣別、報表範圍與會計準則。
- 若資料是使用者提供檔案，寫明檔案類型；若有查外部資料，寫明來源與日期。
- 若做了口徑調整，例如剔除一次性項目或重分類現金流，必須在這段先說。

### `### 核心發現`
- 優先放對經營體質最重要的 3-5 點。
- 每點盡量標示它主要來自哪一張表或哪類附註。
- 重要主張後面附簡短來源註記，例如：
  - `[來源：2025 年年報，綜合損益表 / 現金流量表]`
  - `[來源：10-K Note 2，Revenue Recognition]`

### `### 三表橋接與盈餘品質`
- 至少回答：
  - 淨利是否轉成 CFO
  - 哪些非現金項目影響了表面獲利
  - 哪些營運資金項目在吃現金或釋放現金
  - Capex / 借款 / 股利是否與資產負債表變動一致
- 若只看得到部分資料，明確寫出哪些橋接做不到。

### `### 比率、同業與期間對比`
- 只保留對問題真的有幫助的比率，不要全部列滿。
- 同業比較要先說明比較基礎：
  - 同產業
  - 相近商業模式
  - 相同或已調整的會計口徑
- 若比率在該產業不適用，直接寫「不適用」與原因。

### `### 風險紅旗與待確認事項`
- 每個紅旗至少包含：
  - 觀察到的事實
  - 可能的合理解釋
  - 為何仍值得警戒
  - 還需要追哪類附註或資料
- 若沒有發現強紅旗，也要寫殘餘風險或資料不足處。

## Source annotation pattern

- 重要事實後方附簡短 annotation，例如：
  - `[來源：公司年報，2025-03-15]`
  - `[來源：SEC 10-K，Filed 2026-02-28]`
  - `[來源：公開資訊觀測站，2026-03-20]`
- 若內容是推論，不要假裝成來源事實；改寫成：
  - `推論：...`
  - `待確認：...`

## Forbidden behaviors

- 不要先列一堆比率再回頭補口徑。
- 不要把紅旗直接寫成舞弊定論。
- 不要在沒有估值基準與風險前提時直接給買進/賣出結論。
- 不要忽略幣別、期間長度、合併範圍或會計準則差異。
