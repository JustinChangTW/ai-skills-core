# 財務、投資與房產

分析財報、發掘臺灣隱形冠軍，以及協助臺灣自住買房。

本分類目前收錄 **3 個 Skills**。若任務跨越多個分類，先依主要交付成果選擇 Skill，再視需要交接其他能力。

## Skills 清單

| Skill | 中文名稱 | 主要用途 |
|---|---|---|
| [`financial-statement-analysis`](financial-statement-analysis/README.md) | Financial Statement Analysis | 在使用者要解讀財報、比較三表、檢查盈餘品質或辨識財務紅旗時使用 |
| [`taiwan-hidden-champion-radar`](taiwan-hidden-champion-radar/README.md) | 台灣隱形冠軍雷達 | 掃描、比較及追蹤臺灣可能具全球前三、洲際第一或關鍵利基領導地位的上市櫃、興櫃與未上市企業，查證市占口徑、國際客戶、技術護城河、出口、專利、認證、擴產、徵才、財務品質與市場關注度，並以歷史截點資料執行無前視偏誤回測 |
| [`taiwan-home-buying-guide`](taiwan-home-buying-guide/README.md) | 臺灣買房攻略 | 協助臺灣自住買方從入門、找房、實價比較、高 CP 值物件挖掘、看屋、社區與產權查核、房仲話術、出價議價、房貸預審與合法提高核貸成數，到簽約交屋及退出策略 |

## 使用方式

1. 先從上表選擇最接近主要成果的 Skill。
2. 點進 Skill 的 `README.md` 查看用途、適用情境與快速指令。
3. 在支援 Skills 的環境中直接描述任務，或用 `$skill-name` 明確指定。
4. 真正影響 AI 執行行為的是各 Skill 目錄內的 `SKILL.md`。

回到 [Skills 總目錄](../../CATALOG.md) 或 [版本庫首頁](../../README.md)。
