# 回測規範

## 必要設計

- **母體**：使用當時可列出的全體或固定抽樣框，如特定產業全部上市櫃公司加固定方式抽取未上市公司。
- **截點**：例如 2016-12-31、2019-12-31；所有特徵資料必須在截點前發布。
- **期限**：預先固定三年或五年，不混用。
- **成功標籤**：預先選定可驗證條件，例如期限內達成全球前三／洲際第一，或有獨立來源確認的關鍵利基領導；股票報酬須另建標籤，不能和企業成功混為一談。
- **基準模型**：至少比較隨機、單看營收成長、單看市占及完整雷達。
- **版本**：記錄權重、門檻、資料規則及執行日。

## 偏誤防治

1. 禁止前視：使用資料「發布日」，不是資料所屬年度。
2. 防止幸存者偏誤：保留消失、衰退、下市及未成功公司。
3. 防止選樣偏誤：不能用後來的得獎名單反推全部樣本。
4. 防止資料窺探：訓練期調整後鎖定模型，再測保留期。
5. 防止敘事偏誤：每個高分公司都列可證偽條件；每個錯誤都歸因到資料、標籤或模型。
6. 防止投資混淆：企業成功回測與股票超額報酬回測分開，後者另需處理股息、下市、交易成本及基準指數。

## 最低報告內容

列出 TP、FP、TN、FN、precision、recall、specificity、F1、balanced accuracy；樣本量小時附原始個數，不只百分比。再依分數區間列實際成功率，觀察高分是否真的比低分可靠。
