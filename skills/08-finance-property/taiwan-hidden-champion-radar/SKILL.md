# 台灣隱形冠軍雷達

以 Simon 隱形冠軍、Barney 資源基礎觀點、Porter 群聚及 Ansoff 弱訊號為框架，將「世界級企業能力」與「股票是否便宜」分開。先讀 [評分與證據](references/scoring-and-evidence.md)；執行任何回測時必讀 [回測規範](references/backtesting.md)。

## 掃描流程

1. 定義母體、產業、公司型態、觀察截止日及「隱形」標準；不得只挑已知成功者。
2. 上網查核截止日前可取得的官方、公司申報、海關／產業、專利／認證、客戶及可信研究來源。保存發布日、資料期、直接連結與市占分母。
3. 分開評估：利基地位、護城河、全球化、領先訊號、客戶轉換成本、財務轉化、群聚及證據品質；再扣除集中、循環、治理、仿冒與自我宣稱風險。
4. 市占只有公司宣稱、市場定義過窄或找不到分母時，標示未驗證，不得寫成世界第一。
5. 將公司分為「已證實冠軍、冠軍候選、早期訊號、證據不足、排除」，並列反向證據及下一個可驗證事件。
6. 上市櫃公司如涉及投資，再補財務與估值；未上市公司只作產業、供應鏈及未來上市可能性研究。

## 回測流程

1. 先寫下母體、截點、預測期限、成功標籤、門檻及評分版本，完成後不得因結果改標準。
2. 僅使用在截點當日已公開的資料；晚發布的年報、回溯新聞、後來揭露的客戶或市占全部隔離。
3. 同時納入成功、普通、衰退、下市及資料不足公司，避免幸存者偏誤。
4. 對每個公司保留「截至截點的證據封包」，標示來源發布時間；不能確認當時可見者不得計分。
5. 使用 `scripts/backtest_metrics.py` 計算混淆矩陣、precision、recall、specificity、F1、balanced accuracy 及分數分組成功率。
6. 分開回報訓練期與保留期；只能在訓練期調權重，保留期只評估一次。版本更新後保留舊結果，不覆寫。
7. 逐一分析真陽性、假陽性、真陰性及假陰性，提出有上限的調整，不因單一案例重寫模型。

## 固定輸出

先給一句結論，再列：

1. **範圍與時間點**：母體、產業、截止日、資料涵蓋與排除。
2. **候選排行**：總分、分項分、分類、證據等級及是否可投資。
3. **市占查核**：產品定義、分子、分母、年份、來源與獨立驗證。
4. **領先訊號**：出口、認證、專利、擴產、徵才、國際客戶及出現時間。
5. **護城河與反向證據**：VRIO、轉換成本、競爭者、集中度與替代風險。
6. **回測卡**：版本、截點、標籤、樣本數、混淆矩陣、precision、recall、F1、balanced accuracy、分數校準及資料缺口。
7. **錯誤案例**：誤判與漏判原因、是否涉及前視／幸存者偏誤。
8. **下一步**：需要驗證的事件、責任來源及更新時間。

## 完成標準

- 即時主張已查最新資料，歷史回測沒有使用截止日後資訊。
- 排名包含反例與證據不足者，不只列新聞已報導的成功公司。
- 市占、市場定義及資料年份可追溯；公司宣稱與獨立證據分開。
- 回測揭露母體、標籤、樣本數、門檻、版本與誤判，不只報命中案例。
- 明確區分公司品質、成長可能與股票估值；不把分數當報酬保證。
